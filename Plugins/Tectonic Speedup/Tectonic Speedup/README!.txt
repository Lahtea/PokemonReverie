Place the folder "Chasm Speedup" in the Plugins folder of your download.

Replace the mkxp.json file in the Main folder where Game.exe is with the one in this folder.

Run "Debug Game with PBS Compile.bat".

Close the game and play normally.

Tab is the default key. 

If you want to change the key, you can open the 01_Speed_Up.rb file and change TAB to whatever else. I chose Tab because Tectonic uses all the relevant keys in RPGMaker XP that a controller already would use.
